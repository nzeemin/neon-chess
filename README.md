# neon-chess

Порт шахматной программы `CHESS` с БК-0010 на Союз-Неон ПК 11/16.

![Игровой экран](screenshot/game.png)


## Инструкция

```
1. МАШИНА ЗАПРАШИВАЕТ ВВОДА ДИРЕКТИВ СИМВОЛАМИ  W. ИЛИ B.
2. ПЕРЕД НАЧАЛОМ ИГРЫ ЗАДАЙТЕ УРОВЕНЬ ИГРЫ ДИРЕКТИВОЙ
   D=<УРОВЕНЬ> (1-САМЫЙ НИЗКИЙ, 5-САМЫЙ ВЫСОКИЙ), НАПРИМЕР: D=3.
   УРОВЕНЬ ОТОБРАЖАЕТСЯ ПАРАМЕТРОМ "DEPTH=" В ТАБЛИЦЕ СОСТОЯНИЯ
   В ВЕРХНЕЙ ЧАСТИ ЭКРАНА.
3. ЗАДАЙТЕ ЦВЕТ ФИГУР, ПРИНАДЛЕЖАЩИХ МАШИНЕ:
   PW-МАШИНА ИГРАЕТ БЕЛЫМИ;  PB-МАШИНА ИГРАЕТ ЧЕРНЫМИ.
4. ФИГУРЫ ОБОЗНАЧАЮТСЯ СЛЕДУЮЩИМИ СИМВОЛАМИ:
   P - ПЕШКА                  R - ЛАДЬЯ
   N - КОНЬ                   B - СЛОН
   Q - ФЕРЗЬ                  K - КОРОЛЬ
5. ХОД БЕЗ ВЗЯТИЯ ФИГУРЫ МОЖЕТ БЫТЬ ЗАДАН ОДНИМ ИЗ СЛЕДУЮЩИХ СПОСОБОВ:
   а)<ФИГУРА>-<ПОЗИЦИЯ>  (НАПР.:  P-E4)
   б)<ФИГУРА>/<ПОЗИЦИЯ>-<ПОЗИЦИЯ>  (НАПР.: P/E2-E4)
6. ХОД СО ВЗЯТИЕМ ФИГУРЫ МОЖЕТ БЫТЬ ЗАДАН ОДНИМ ИЗ СЛЕДУЮЩИХ СПОСОБОВ:
   а)<ФИГ.>:<ФИГ.>            (P:P)
   б)<ФИГ.>/<ПОЗ.>:<ФИГ.>     (P/E4:P)
   в)<ФИГ.>:<ФИГ.>/<ПОЗ.>     (P:P/D5)
   г)<ФИГ.>/<ПОЗ.>:<ФИГ.>/<ПОЗ.>   (P/E4:P/D5)
6. ПОСЛЕ ВВОДА УРОВНЯ ИГРЫ, ВВОДА ХОДА НЕОБХОДИМО НАЖАТЬ КЛАВИШУ
   <ВВОД>. ПРИ НЕПРАВИЛЬНО ВВЕДЕННОЙ КОМАНДЕ ВОЗНИКАЕТ НАДПИСЬ
   ILLEGAL INPUT  И МАШИНА ЖДЕТ ПОВТОРНОГО ВВОДА.
   ДЛЯ ОТМЕНЫ НАБРАННОЙ СТРОКИ ДО НАЖАТИЯ КЛАВИШИ <ВВОД>
   ПОЛЬЗУЙТЕСЬ КЛАВИШЕЙ <ЗБ>, И ПОСЛЕ ПОЯВЛЕНИЯ НАДПИСИ  ILLEGAL
   INPUT  ПОВТОРИТЕ ВВОД СТРОКИ.
7. НАДПИСЬ  AMBIGOUS  ВОЗНИКАЕТ, ЕСЛИ ВВЕДЕННЫЙ ВАМИ ХОД
   НЕОДНОЗНАЧНО ОПРЕДЕЛЯЕТ ПЕРЕМЕЩЕНИЕ ФИГУРЫ. В ЭТОМ СЛУЧАЕ
   ПОЛЬЗУЙТЕСЬ БОЛЕЕ ИНФОРМАТИВНОЙ ЗАПИСЬЮ ХОДА (СМ. ПУНКТЫ 5,6).
8. ДИРЕКТИВА  RE  ОЗНАЧАЕТ ЧТО ВЫ СДАЕТЕСЬ, ПРИ ЭТОМ МАШИНА
   РАССТАВЛЯЕТ ФИГУРЫ ЗАНОВО.
9. ДИРЕКТИВА  PN  ОТМЕНЯЕТ РАНЕЕ НАЗНАЧЕННЫЕ ДИРЕКТИВЫ
   PW ИЛИ  PB  И МОЖЕТ ПРИМЕНЯТЬСЯ ДЛЯ РЕШЕНИЯ ЗАДАЧ.
9. ВЫ МОЖЕТЕ САМИ РАЗМЕСТИТЬ ФИГУРЫ НА ДОСКЕ. ДЛЯ ЭТОГО НАБЕРИТЕ
   ДИРЕКТИВУ  AP  И ПОСЛЕ ПОЯВЛЕНИЯ НАДПИСИ  P.  ВВЕДИТЕ СЛЕДУЮЩИЕ
   СИМВОЛЫ:
   <ЦВЕТ><ФИГ.><ПОЗ.>  (ЦВЕТ: W-БЕЛАЯ;  B-ЧЕРНАЯ)
   НАПРИМЕРИМЕР:  WNE3  ЕСЛИ ВЫ ХОТИТЕ СТЕРЕТЬ В ЭТОЙ ПОЗИЦИИ
   ФИГУРУ, ТО ВМЕСТО <ЦВЕТ><ФИГ.> НАБЕРИТЕ 0 НАПР.: 0Е3
   ВЫЙТИ ИЗ РЕЖИМА  AP  МОЖНО НАЖАТИЕМ КЛАВИШИ <ВВОД>.
```

## Команды

В процессе разбора CHESS.BIN выяснилось, что программа поддерживает больше команд, чем указано в описании. Ниже полный список, звёздочкой помечены не описанные команды:
```
"PW" - компьютер за белых
"PB" - компьютер за чёрных
"PN" - сброс PB/PW
"IN"* - выводит запрос "ИМЯ??" и сразу возвращается к запросу команды - похоже, заглушка на загрузку позиции из файла
"RE" (Resign) - сдаться
"SK"* (Skip) - выглядит как пропуск хода
"W="* (Width) - меняет параметр WIDTH в строке состояния, видимо что-то про расчёт хода
"D=" (Depth) - задаёт уровень игры 1..5
"OT"* - выводит запрос "ИМЯ??" и сразу возвращается к запросу команды - похоже, заглушка на сохранение позиции в файл
"AP" - расстановка фигур
"T="* - тестовый выход? сохраняет (SP) и SP и переходит на 160722 - на БК-0010 выглядит как выход в Бейсик - в версии для Неона заменил на "EX"
"CL"* (Clear) - очищает доску
```


## Идея проекта

Оригинальная программа CHESS написана для БК-0010 и использует его EMT-запросы
к монитору (клавиатура, вывод символов/строк, курсор). Порт запускает
дизассемблированный/восстановленный код игры (`CHESS.MAC`) как есть, а все
обращения к БК-0010 эмулируются на стороне Союз-Неон:

- `MAIN.MAC` — загрузчик: создаёт видео-область через `ARCRE`/`VWCRE`/`PLCRE`,
  устанавливает свой обработчик EMT (`EMTEMU`) и передаёт управление в код игры.
- `BKEMUL.MAC` — эмуляция части драйвер-мониторного модуля БК-0010 (вывод символов, строк, курсор, клавиатура и т.д.), необходимой игре.
- `CHESS.MAC` — сама игра: полностью выверенный побайтно дизассемблированный
  код оригинального `CHESS.BIN` для БК-0010, с последующими небольшими измененими.


## Текущее состояние

Игра запускается, показывает страницы инструкции, рисует доску и принимает
ходы. Команды `PW`/`PB` включают режим "компьютер играет за белых/чёрных" —
работает полный режим "компьютер против компьютера".

Добавлен выход из программы командой `EX`.

Не сделано:
 - мелодии


## Сборка

```
!compilelink.bat
```

Собирает `MAIN.MAC` через MACRO-11/LINK (RT-11) в `CHESS.SAV`.
Используется "эмулятор RT-11" от Patron.


## Запуск

```
!runneonbtl.bat
```

Кладёт `CHESS.SAV` на образ диска и запускает эмулятор NeonBTL.
